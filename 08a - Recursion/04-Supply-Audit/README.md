# Exercise 4 Supply audit

Open this folder as an IntelliJ project. Use your existing course JDK. Open `src/Main.java` and run `Main` using the green run icon. If IntelliJ does not recognise `src`, right-click it and choose **Mark Directory as > Sources Root**. No package or module is needed.

1. Read the scenario and core tasks in `src/Main.java`.
2. Use `Exercise-4-Review.docx` as you work.
3. Predict results before running the test cases. Record your traces in your notebook.
4. Open `Exercise-4-Extensions.docx` after completing the core task.

Each exercise is independent. Open one child project at a time; each has its own `Main` class. Starter return values marked TODO are placeholders, not finished solutions.
